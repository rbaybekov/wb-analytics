# 🌐 Полная версия WB Analytics - Инструкция по использованию

## ✅ Статус: Полная версия запущена и работает!

**Сервер запущен на:** http://localhost:5000  
**Статус:** ✅ Работает (HTTP 200)

## 🚀 Как использовать полную версию

### 1. Откройте браузер
Перейдите по адресу: **http://localhost:5000**

### 2. Авторизация через SMS
1. **Нажмите "Войти"** на главной странице
2. **Введите номер телефона:** +79264845850 (уже заполнен)
3. **Нажмите "Отправить SMS код"**
4. **Дождитесь SMS** на номер +79264845850
5. **Введите код из SMS** в поле
6. **Нажмите "Подтвердить"**

### 3. Панель управления
После успешной авторизации вы попадете в панель управления с:

#### 📊 Статистика товаров
- **Всего товаров** - общее количество
- **В наличии** - товары с остатком > 0
- **Средняя цена** - средняя цена всех товаров
- **Общие продажи** - сумма всех продаж

#### 🔍 Фильтрация и поиск
- **Поиск по названию/артикулу** - быстрый поиск
- **Фильтр по категории** - выбор категории товаров
- **Фильтр по бренду** - выбор бренда
- **Фильтр по остатку** - в наличии/мало/нет в наличии

#### 📋 Таблица товаров
- **Артикул** - уникальный номер товара
- **Название** - полное название товара
- **Цена** - текущая цена
- **Старая цена** - цена до скидки
- **Скидка** - процент скидки
- **Остаток** - количество на складе
- **Продажи** - количество проданных единиц
- **Рейтинг** - оценка товара
- **Отзывы** - количество отзывов
- **Действия** - кнопка "Просмотр" для детальной информации

#### 👁️ Детальная информация
- **Модальное окно** с полной информацией о товаре
- **Ссылка на Wildberries** - переход к товару на сайте
- **Все параметры** - цены, остатки, продажи, рейтинги

#### 💾 Экспорт данных
- **CSV формат** - скачивание в Excel-совместимом формате
- **Фильтрация** - экспорт только отфильтрованных данных
- **Автоматическое именование** - файл с текущей датой
