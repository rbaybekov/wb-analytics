# 🌐 Веб-версия парсера Wildberries

## 🚀 Запуск веб-приложения

### 1. Запуск сервера

```bash
python wb_web_app.py
```

### 2. Открытие в браузере

Откройте браузер и перейдите по адресу:
**http://localhost:5000**

## 📱 Авторизация через SMS

### Пошаговая инструкция:

1. **Откройте главную страницу** - http://localhost:5000
2. **Нажмите "Войти"** или перейдите на страницу авторизации
3. **Введите номер телефона** - +79264845850 (уже заполнен по умолчанию)
4. **Нажмите "Отправить SMS код"**
5. **Введите код из SMS** сообщения
6. **Нажмите "Подтвердить"**

## 🔧 Технические особенности

### Backend (Python Flask)
- **Авторизация:** SMS код через официальный API
- **Парсинг:** Получение данных через Seller API
- **Сессии:** Сохранение токенов авторизации
- **API:** RESTful endpoints для фронтенда

### Frontend (HTML/CSS/JavaScript)
- **Дизайн:** Bootstrap 5 + Font Awesome
- **Интерфейс:** Адаптивный дизайн
- **Интерактивность:** AJAX запросы
- **UX:** Уведомления, загрузка, фильтрация

## 📊 API Endpoints

### Авторизация
- `POST /api/send-sms` - Отправка SMS кода
- `POST /api/verify-sms` - Проверка SMS кода

### Данные
- `GET /api/products` - Список товаров
- `GET /api/product/<article>` - Информация о товаре

### Страницы
- `GET /` - Главная страница
- `GET /login` - Страница авторизации
- `GET /dashboard` - Панель управления
- `GET /logout` - Выход из системы

## 🛡️ Безопасность

- **Сессии:** Flask sessions с секретным ключом
- **Токены:** JWT токены для API
- **Валидация:** Проверка всех входных данных
- **CORS:** Настройка для веб-интерфейса

## 🚨 Устранение неполадок

### Проблемы с авторизацией
1. Проверьте номер телефона
2. Убедитесь, что SMS код получен
3. Проверьте интернет-соединение

### Проблемы с данными
1. Обновите страницу
2. Проверьте авторизацию
3. Перезапустите сервер

### Проблемы с сервером
1. Проверьте, что порт 5000 свободен
2. Убедитесь, что Flask установлен
3. Проверьте логи в консоли
