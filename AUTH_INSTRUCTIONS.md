# 🚀 Инструкция по авторизации в Wildberries Seller API

## 📋 Пошаговая инструкция

### 1. Авторизация через браузер

1. **Откройте браузер Chrome**
2. **Перейдите на https://seller.wildberries.ru/**
3. **Введите номер телефона: +79264845850**
4. **Нажмите кнопку "Отправить код" или "Получить код"**
5. **Введите SMS код, который придет на телефон**
6. **Нажмите кнопку "Войти" или "Подтвердить"**
7. **Дождитесь успешной авторизации**

### 2. Получение токена

1. **Откройте инструменты разработчика (F12)**
2. **Перейдите на вкладку "Application" или "Приложение"**
3. **В левом меню найдите "Cookies" → "https://seller.wildberries.ru"**
4. **Найдите cookie с именем содержащим:**
   - `token`
   - `jwt`
   - `auth`
   - `wb`
   - `session`
5. **Скопируйте значение этого cookie**

### 3. Сохранение токена

Создайте файл `wb_token.json` в папке проекта со следующим содержимым:

```json
{
  "token": "ВАШ_ТОКЕН_ЗДЕСЬ",
  "method": "Cookie",
  "timestamp": 1736905823,
  "date": "2025-10-22 16:12:13"
}
```

### 4. Запуск парсера

После сохранения токена запустите:

```bash
python wb_final_parser.py
```

## 🔧 Альтернативный способ

Если у вас есть готовый токен, можете запустить:

```bash
python wb_manual_auth.py
```

И ввести токен вручную для тестирования.

## 📞 Поддержка

Если возникли проблемы:
1. Убедитесь, что авторизация прошла успешно
2. Проверьте, что токен скопирован полностью
3. Убедитесь, что файл `wb_token.json` создан правильно
