# 🌐 WB Analytics - Веб-версия парсера Wildberries

[![Python](https://img.shields.io/badge/Python-3.7+-blue.svg)](https://python.org)
[![Flask](https://img.shields.io/badge/Flask-3.1.2-green.svg)](https://flask.palletsprojects.com)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Полнофункциональная веб-версия парсера Wildberries с авторизацией через SMS код и интеграцией с официальным Seller API.

## 🚀 Демо

**Локальный запуск:** http://localhost:5000

## ✨ Возможности

### 🔐 SMS Авторизация
- ✅ Реальная авторизация через SMS код
- ✅ Интеграция с официальным Wildberries Seller API
- ✅ JWT токены для безопасного доступа
- ✅ Защищенные сессии Flask

### 📊 Аналитика товаров
- ✅ Полная статистика по товарам
- ✅ Цены, остатки, продажи в реальном времени
- ✅ Рейтинги и отзывы покупателей
- ✅ История изменений цен

### 🎨 Современный интерфейс
- ✅ Адаптивный дизайн Bootstrap 5
- ✅ Интерактивные фильтры и поиск
- ✅ Модальные окна с детальной информацией
- ✅ Экспорт данных в CSV формате

### 🔍 Фильтрация и поиск
- ✅ Поиск по названию и артикулу
- ✅ Фильтр по категории и бренду
- ✅ Фильтр по остатку на складе
- ✅ Сортировка по различным параметрам

## 🛠️ Установка и запуск

### Требования
- Python 3.7+
- Интернет-соединение
- Номер телефона для SMS авторизации

### Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/yourusername/wb-analytics.git
   cd wb-analytics
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение:**
   ```bash
   python wb_web_app.py
   ```

4. **Откройте браузер:**
   ```
   http://localhost:5000
   ```

## 📱 Использование

### 1. Авторизация
1. Откройте http://localhost:5000
2. Нажмите "Войти"
3. Введите номер телефона: +79264845850
4. Нажмите "Отправить SMS код"
5. Введите код из SMS сообщения
6. Нажмите "Подтвердить"

### 2. Панель управления
- **Статистика:** Общее количество товаров, в наличии, средняя цена, продажи
- **Поиск:** Быстрый поиск по названию или артикулу
- **Фильтры:** По категории, бренду, остатку
- **Таблица:** Полная информация о товарах
- **Экспорт:** Скачивание данных в CSV формате

## 🏗️ Архитектура

### Backend (Python Flask)
- **Flask** - веб-фреймворк
- **Requests** - HTTP клиент для API
- **Pandas** - обработка данных
- **Sessions** - управление сессиями

### Frontend (Web)
- **Bootstrap 5** - CSS фреймворк
- **Font Awesome** - иконки
- **JavaScript** - интерактивность
- **AJAX** - асинхронные запросы

### API Integration
- **Wildberries Seller API** - официальный API
- **SMS Auth** - авторизация через SMS
- **JWT Tokens** - токены авторизации

## 🔧 API Endpoints

### Авторизация
- `POST /api/send-sms` - Отправка SMS кода
- `POST /api/verify-sms` - Проверка SMS кода

### Данные
- `GET /api/products` - Список товаров
- `GET /api/product/<article>` - Информация о товаре

### Страницы
- `GET /` - Главная страница
- `GET /login` - Страница авторизации
- `GET /dashboard` - Панель управления
- `GET /logout` - Выход из системы

## 🚀 Развертывание

### Локальное развертывание
```bash
python wb_web_app.py
```

### Продакшен развертывание
```bash
# Используйте WSGI сервер для продакшена
gunicorn -w 4 -b 0.0.0.0:5000 wb_web_app:app
```

### Docker развертывание
```dockerfile
FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 5000
CMD ["python", "wb_web_app.py"]
```
